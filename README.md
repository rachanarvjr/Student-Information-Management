# 🎓 Menu-Driven Student Information System

## 📌 About the Project
The Menu-Driven Student Information System is a simple Python project that helps users manage student records. It allows users to add, view, search, and delete student information through a menu-driven interface.

## ✨ Features
- Add new student records.
- View all registered students.
- Search for a student using their roll number.
- Delete student records.
- Simple and user-friendly menu.

## 🛠️ Technologies Used
- Python 3

## 🚀 How to Run
1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python app.py
   ```

6. Select an option from the menu and follow the instructions.

## 🎯 Objective
To demonstrate Python programming concepts such as dictionaries, functions, loops, conditional statements, and user input through a practical student-record management application.

## ⚠️ Note
Student records are stored temporarily in memory and will be lost when the program exits.
